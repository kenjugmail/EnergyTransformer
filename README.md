# EnergyTransformer

Research on language models whose recurrent memory is represented by coefficients of energy functions, with selective retention, multiple reads, and explicitly audited computation.

## Scope

This is experimental software, not an instruction-following assistant or evidence of universal superiority over Transformers. The project distinguishes trained language components, structured-memory components, numerical optimization experiments, and proposed integrations. The name does not imply affiliation with other published Energy Transformer projects.

## Research status

The preceding v13 component stores protected associations from typed records. The next integration is a learned text-to-memory bridge and memory-conditioned answers. Code, reports, reproducibility information, and publication status will be recorded alongside the implementation. Historical results must not be interpreted as new runs.

## Publication and privacy

Repository visibility is unchanged. Only project artifacts are in scope; training corpora, credentials, private conversation transcripts, and unrelated personal information are not intended for publication. Original third-party terms remain applicable; no new blanket license is imposed here.
