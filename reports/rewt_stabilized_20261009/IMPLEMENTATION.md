# Implemented research repairs and replacement evaluation

The implementation is in the independent [REWT package](/home/kt/Documents/EnergyTransformer/rewt/README.md). All model weights originate from this project's training. Inference keeps weights fixed and accepts workspace/output changes only when the same complete conditional energy decreases.

The follow-up implements centered output geometry across the whole energy and its analytic derivatives, dimension-aware mode directions, noisy initial training guesses, stronger wrong-byte energy comparisons, a local refinement-repair loss, randomized training depth, a balanced reasoning curriculum, first-invalid-step feedback, causal history caching, optional bounded inference stopping, and residual Fourier/EMA gradient filters that retain the raw gradient. Fourteen validation-only screens chose 32 modes, frequency bound 2, step size 0.25, learning rate 0.004 and ordinary clipping for the primary comparison. The filters remain measured alternatives rather than unearned default improvements.

The completed language fits each process 1,048,576 target bytes (256 updates, batch 32, context 128), approximately 17.1 times the original pilot's byte budget. Five parameter-matched variants use three seeds: Transformer, raw Fourier REWT, revised non-Fourier energy, revised Fourier REWT and full REWT. Reasoning copies receive 800 adaptation updates with batch 16. Teacher preparation and every auxiliary forward/loss are included in measured training cost.

The first follow-up was stopped after full-model reasoning instability. An exact saved replay found a finite gradient whose float32 norm overflowed; wider norm arithmetic resolved that diagnostic error, but further replay exposed actual non-finite gradients through a long recurrent backward chain. The repaired full reasoning fits detach carried latent-state gradients every sixteen observed tokens during training. All forward state values and observed history remain present, and inference retains the full 128-byte window. This bounds temporal training credit and is a methodological limitation as well as a stability repair. Actual non-finite components still fail the fit.

This replacement study reuses all fifteen completed language fits and twelve completed control reasoning fits with byte-identical checkpoints and original source/training provenance. All three full reasoning fits restart from their completed language weights under the same new stability rule. Every reused checkpoint also passes a recorded bitwise inference comparison between the parent's archived code and the current code. The [restart runner](/home/kt/Documents/EnergyTransformer/rewt/stabilize.py) preserves this ledger and stops remaining workers immediately if one fails.

The new held-out language windows and sampled-text prefixes exclude both previous experiments' test samples. The new 300 synthetic test identities exclude both previous test sets and remain disjoint from the unchanged training/validation data. These declarations are saved before restarted fitting. No partial score from the stopped attempt enters the replacement study. The primary comparison remains a bundle of repairs and cannot isolate each component's causal contribution.

Before the replacement run, **50 tests passed**. Tests cover analytic gradients, output-shift invariance, retained forward memory, training-only temporal boundaries, fixed inference weights, causal/chunked execution, energy acceptance, corruption, process annotations, large finite-gradient clipping, actual non-finite rejection, residual filters, exact optimizer continuation and the checkpoint reuse guard. Separate small end-to-end smoke runs verified generation, reporting and isolated profiling.

Raw text continuations and greedy reasoning outputs have been scored. Arithmetic/rule reasoning and recall remain separate; full reasoning correctness requires the final answer and every intermediate step. All 450 anonymous primary text samples were read and rated by the assistant before locking the ratings and joining model identities. Human fluency/coherence/relevance ratings remain pending. The [completed findings](/home/kt/Documents/EnergyTransformer/reports/rewt_stabilized_20261009/FINDINGS.md) distinguish the verified geometry repair from the lack of a clear quality gain and the full model's remaining optimization spikes.
