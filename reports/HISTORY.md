# Research lineage: original archives preserved

These are inherited stages, not newly executed experiments in v14. Consult the original reports and raw results; negative controls are part of the record.

| Stage | Focus | Key boundary |
|---|---|---|
| v1 | Compressed adaptive energy graphs | Classical robust solver matched the proposed method |
| v2 | Representation repair | Supplied candidate families, not unrestricted discovery |
| v3 | Learned program proposals | Bidirectional classical search was stronger |
| v4 | Energy function as restartable state | Same computation as matched classical inference |
| v5 | Tiny energy-state byte model | GRU baseline was better |
| v6 | Transported energy memory | Equal-update win, not universal Transformer dominance |
| v7 | MLA-inspired compressed retrieval | Continued energy-only training was the stronger control |
| v8 | Spectral functions and guarded jumps | No language advantage from multiscale reads |
| v9 | Direct function reads and easy-case bounds | Faster read, simpler control still better |
| v10 | Second query of existing memory | Small gain with extra cost |
| v11 | Reader fusion and compaction | Modest size/runtime trade-off |
| v12 | Compiled runtime and quantized state | No new weights; forgetting limitation exposed |
| v13 | Structured protected retention | Typed records supplied; dictionary matched |
| v14 | Text-to-memory and bounded learned answers | Supported grammar succeeds; unseen wording fails |
