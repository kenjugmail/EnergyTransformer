## 2. The additive implementation

The new package forecasts a candidate joint trajectory Y given a past history C:

    p(Y | C) = sum_k pi_k(C) Normal(Y; mu_k(C), Sigma_k(C))
    E(Y | C) = -log p(Y | C)

Y is the concatenation of +1/+4/+16/+64 future steps and eight summary variables.
Sigma_k = diag(scale_k) L_k L_k^T diag(scale_k), where L_k is a learned, invertible,
row-normalized triangular factor. Its off-diagonal elements couple horizons and
variables. Component scales and means depend on C; correlation factors are learned
per component but shared across contexts. This is not an unrestricted dynamic full
covariance at every prefix. One component gives a convex Gaussian control. Three
components can produce distinct basins and nonlinear gradients.

This is an explicitly normalized, tractable energy-based density, not a renamed
uncalibrated regression error. Standard Gaussian-mixture mathematics is prior art.
At fixed C, all energy parameters are held fixed during refinement. The gradient is
responsibility-weighted precision times residual. The objective is exact NLL, so no
contrastive-normalizer estimate or MCMC approximation is required.

Each final-layer head contributes mean(log(P)) and a fixed signed projection of
M=S/P. Four heads therefore give eight quantities. The projection is deterministic,
not fitted on the test set. These are lossy sketches, NOT all coefficients and NOT
natural-language semantics. The original P/S and all LM parameters remain unchanged.
The output is statistical support over sketches; some Gaussian tail combinations
need not correspond to realizable full model states.

A ForecastSession retains 16 observed sketches (512 raw bytes at this dimension)
in addition to the existing model state. It never installs a guessed state, changes
logits, approves a memory edit, or skips the unobserved bytes. A fresh forecast is a
new conditional function; it is not evidence that one global energy always decreases
as real input arrives.

## 3. Fourier scope

The spectral variant applies a complete orthonormal real Fourier basis only along
the 16 observed time steps. It preserves all input information and parameter count
relative to the ordinary three-component model. It is a representation/optimization
bias, not future access, an energy-barrier removal theorem, or an added harmonic
potential over the candidate Y. All four horizons are predicted jointly; a separate
learned far-to-near hierarchical infilling system has NOT been implemented.

## 4. Executed experiments

CPU only, PyTorch 2.10.0+cpu. The local 10.6M weights are not available here. The
teacher is the original 972,896-parameter v21 checkpoint, SHA-256
`78b4662a3c30d2e1a8905340e1c465eb1f83c34e98bcfc28177b2dbfb93ea06b`.
It loads strictly into a functional copy of the inspected current energy model;
only source comments/docstrings were condensed. That standalone copy is explicitly
separate from, and never pushed over, the live repository implementation.

For the actual state-forecast task: local Gensim Lee Background byte documents,
max 384 bytes/document, 16-step histories, origins every 16 bytes, horizons 1/4/16/64.
Exact document duplicates are grouped BEFORE splitting. This gives 231 train
subjects/documents (4,617 windows), 30 validation documents (600 windows), and 32 test
documents (634 windows). Mean/standard-deviation normalization uses only training
histories. Origins/futures never cross documents. Frozen teacher targets cannot
collapse through forecast-head training. The corpus domain and some text have been
used in earlier project studies: this is not an untouched new language benchmark.
The teacher itself was trained on the older Wikipedia fixture, not this head dataset.
No corpus bytes are included in this package; numeric summary tensors are retained.

Twelve native head fits: 4 conditions x seeds 11/22/33, each 600 AdamW updates,
batch64, max LR .001, clipping1, cosine schedule; 38,400 presented forecast windows
per fit, repeatedly sampled from the finite set. Batches are paired by seed. Validation
NLL selects each checkpoint. Spectral has the best mean validation NLL; the representative
export uses seed11 rather than selecting the lowest test-score seed. No model was
refitted after inspecting final test results. The smaller Gaussian controls have fewer
parameters; only mixture versus spectral is exactly parameter matched. There is no
FLOP or latency-matched superiority claim.

Six more fits use an independently generated two-branch multivariate process: joint
Gaussian versus mixture, 3 seeds, same 600-update budget. The branch sign is intentionally
unpredictable from the past. This checks multimodal density learning, not reasoning.
Total: 18 trained forecast heads; no new language-model fit or DGX run.

## 5. Native-state results

All mean-squared errors use standardized SKETCH coordinates. NLL is nats per forecast
coordinate, not bits per byte or language perplexity. Lower is better.

| Method | Learned coefficients | Mean MSE | NLL/coordinate |
|---|---:|---:|---:|
| Persistence | 0 | 1.727229 | not scored |
| Constant train mean | 0 | 1.029686 | not scored |
| Validation-selected ridge | 4,128 | **0.880202** | not scored |
| Independent Gaussian | 28,001 | 0.909344 | 1.308834 |
| Joint Gaussian | 29,025 | 0.910382 | 1.258867 |
| Joint mixture | 43,683 | 0.913629 | 1.224147 |
| Fourier-history joint mixture | 43,683 | 0.897245 | **1.214732** |

Ridge is the best tested point forecaster overall. Among the neural density heads,
correlation and mixture flexibility improve likelihood, not necessarily MSE. Fourier
versus temporal mixture changes MSE by -0.016384, paired document-bootstrap interval
[-0.020490,-0.012025], and NLL by -0.009415, interval [-0.014161,-0.004640]. These are
conditional on 32 small reused-domain test groups, shared targets, three fits and the
chosen study. They do not correct all historical model selection or semantic overlap.

The long-horizon failure matters. At +1 byte, spectral MSE is 0.55722 versus the constant
mean's 1.02783. At +64, it is **1.10956 versus 1.05286**: no useful long-horizon point
advantage is demonstrated. Even ridge has +64 MSE 1.07328. Forecasting multiple future
steps is implemented; accurately skipping 64 bytes is NOT demonstrated.

A seed11 marginal-interval diagnostic with 512 samples gives about 88.3% coverage for
nominal 90% spectral-mixture intervals. This is not calibrated joint-trajectory coverage,
a factual-confidence score, or an OOD guarantee. Other heads are also slightly below90%.

## 6. What makes the energy nonlinear, and why descent is not truth

On the independent branching control, mean NLL/coordinate is 0.672329 for the joint
Gaussian and **-0.383323** for the mixture. Negative continuous NLL is valid when density
exceeds one in the chosen units. MSEs are nearly unchanged (1.718256 vs 1.721095).
The mixture captures alternate futures; the conditional mean remains preferable for
squared error but can lie between likely branches. An actual trained energy slice
shows multiple minima; this is NOT evidence of fractal basins or transient chaos.

Refinement uses per-example backtracking and holds the conditional function fixed.
Across four representative native heads x192 contexts x6 steps there are zero accepted
energy increases above1e-6. For the spectral head, mean energy changes only 18.795418
->18.795153; the refined mode's MSE is0.946291, worse than the conditional mean's0.898175
on that subset. A lower energy does not imply a better squared-error forecast or a
more correct next word. Refinement is local MAP search, not exact sampling or a global
optimality certificate. Multi-candidate ranking is a diagnostic with synthetic candidate
sets; it is not open-ended accuracy or factual verification.

## 7. Checks, amendments and deployment scope

The focused suite passes27 tests. It covers exact density agreement with PyTorch's
MultivariateNormal/MixtureSameFamily, candidate and parameter gradients, nonzero cross
variable curvature, a true nonconvex mixture control, sampling covariance, Fourier
orthogonality, target alignment, document limits, fixed-energy refinement, and invalid
input rejection. Integration checks show unchanged language logits with/without the
sidecar and identical earlier summaries under future-byte perturbation. A fresh process
restores the LM state plus summary history and reproduces language logits and forecast
energy exactly. A separate short interrupted head-training test reproduces final model,
AdamW state and sampled batch hashes. These are same-environment CPU checks.

An initial empty-window unit test found an arange-boundary bug; it was fixed before
primary fits. The initial log is retained. After scoring, sampling was changed to avoid
materializing one D-by-D covariance factor per drawn trajectory. This changes only
floating-point grouping of samples, not trained weights, evaluated NLL/MSE, or energy.
Calibration and timing are labelled secondary diagnostics. Sampling covariance tests
were rerun. The suite is not the full historical repository's test count.

Seed11 CPU head-forward medians are roughly0.126-0.133 ms, excluding teacher execution,
summary construction, energy minimization and sampling. They are not a decoding speedup.
The layer has a dense D-by-D covariance per component; larger horizons/channels need
block/low-rank structure before treating it as a scalable design. GPU is untested.

`prepare_enwik8.py` targets the actual repository checkpoint schema and fixed90M/5M/5M
boundaries, with a supplied checksum, disjoint blocks, a bounded wall-time budget and
idle-GPU check. Its indexing is unit-tested; actual10.6M extraction was not performed.
Do not reuse the archived973K forecasting head on that different checkpoint.

## 8. Next decision

Retain the existing decoder. Run the frozen-head experiment on the actual10.6M model
and fixed enwik8 splits, then evaluate whether useful +16/+64 predictability exists.
Only after that, test a zero-initialized, opt-in forecast-to-decoder residual with
next-byte loss plus forecast NLL, matched added parameters and training work. An EMA
or separately frozen target is needed if the backbone becomes trainable; a moving
self-target can collapse. That joint LM experiment is proposed, NOT executed here.

Forecasted summaries do not determine unobserved intermediate tokens. Lossless skip-ahead
requires a token proposal and exact verification/rejection procedure, not overwriting
P/S with an estimated future. No speculative decoder is implemented in this patch.
